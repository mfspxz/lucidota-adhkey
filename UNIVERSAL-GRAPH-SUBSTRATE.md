# Universal Graph Substrate — the unification

**Source:** Zackary's synthesis, 2026-10-06. Status: ARCHITECTURE.
This is the capstone: the joint between everything built.

## The deeper layer

> There is one graph-shaped information machine. Domains mostly change
> the vocabulary, constraints, evidence sources, and transition rules.

Not "a hunch graph," "a failure graph," "a project graph," "an identity
graph" as different machines. One substrate; task-scoped views.

```
UNIVERSAL GRAPH
    ├── UNIVERSAL STATEMENT ── entities, relations
    ├── UNIVERSAL EVENT ── observations, actions
    └── DERIVED STATE ── CLAIMED / ESTABLISHED / AUTHORIZED
            └── SHAPE MATCHING → PREDICTION → ACTION
                → OBSERVATION → UPDATE
```

GO-50 = universal semantic substrate. D-25 = domain vocabulary /
constraints. C-25 = application projection.

## The universal record (dimensions, not field names)

WHO WHAT WHEN WHERE WHY HOW TYPE RELATION SOURCE EVIDENCE STATE TIME
SEQUENCE CONTEXT — dimensions of every event/statement, across domains:

- uranium anomaly: sensor→observed→anomaly; location→at→boundary;
  instrument→used→survey
- software failure: test→observed→bypass; commit→introduced→behavior;
  court→challenged→claim
- journalism: source→claims→event; document→contradicts→source
- fish survey: survey→sampled→location; method→has_detection_p→p
- hunch: observations→activate→graph region; region→resembles→prior
  shape; shape→predicts→explanation; operator→suspects→explanation

Same machine. Different nouns, predicates, adapters, policies.

## Views, not realities

```
WORLD GRAPH ── SOFTWARE VIEW (project/failure shape)
            ── GEOLOGY VIEW (uranium shape, nonconformity)
            ── IDENTITY VIEW (adhkey, authority)
            ── HUNCH ENGINE ── COURT/TEST ── PREDICTION
```

The views are projections, not separate realities. Keep organelles
separate (specialization is useful); make the semantic substrate
interoperable (reality doesn't respect application boundaries).

Organelle = vocabulary + policy + evidence adapters, as a projection
over the substrate. MCP servers = wire interfaces to organelles.

## Shape matching at the center

```
UNIVERSAL GRAPH ── CURRENT SHAPE vs HISTORY SHAPES
    → STRUCTURAL MATCH → KNOWN PATTERN (prediction)
                       → NOVEL PATTERN (hunch)
    → DISCRIMINATING OBSERVATION → COURT → OUTCOME → SHAPE UPDATE
```

Computational pattern recognition over accumulated relational
structure — and the apparatus that can test the 98% hunch claim
instead of believing it.

## The layer stack

- Computer: ENTER READ WRITE COPY SAVE FIND TRANSFORM DELETE TRANSMIT MATH
- Semantic: OBSERVE RELATE COMPARE INFER PREDICT DECIDE ACT VERIFY UPDATE
- Graph: NODE EDGE EVENT STATEMENT EVIDENCE STATE TIME PROVENANCE SHAPE
- Epistemic: CLAIMED ESTABLISHED AUTHORIZED
- Adversarial: ATTACK CONTRADICT REFUTE EXPLOIT RECOVER ADAPT
- Cognitive: RECOGNIZE HUNCH INVESTIGATE LEARN

Same information transformations; different semantic interpretations.

## The final ambition

Learn the shapes of graph *transitions*, not just graph states:

> "When a graph enters configuration X, what tends to happen next?"

Prediction falls out of the system. Dynamics, not statics.
